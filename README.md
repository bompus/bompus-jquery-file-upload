# bompus-jquery-file-upload (deprecated)

> **Moved / superseded by [`bompus-chunked-file-upload`](https://github.com/bompus/bompus-chunked-file-upload) v2.0.0** (vanilla JS, no jQuery).
>
> - New API: `BompusFileUpload(…)` (was `$.bompusFileUpload`)
> - New CDN: `https://cdn.jsdelivr.net/gh/bompus/bompus-chunked-file-upload@2.0.0/bompus-chunked-file-upload.min.js`
>
> This repository remains available so existing **1.0.x** jsDelivr / GitHub URLs keep working. No further feature development here.

Upload files from a web browser in parallel chunks (jQuery + async.js era).
